HD Evaluation: Adaptive Edge Filtering for Scalable Smart AC IoT

Research Technique Applied

This HD evaluation applies adaptive edge filtering to the Smart AC IoT system. The baseline design forwards every telemetry event to cloud microservices. The improved design keeps all warning and critical events, but samples low-priority comfortable and empty-room events at the edge before sending data to cloud services.

Scenario: 60% comfortable, 10% empty-room, 20% slightly uncomfortable, 7% too hot/crowded, 3% critical. Low-priority sample rate: 1 in 5.

The adaptive design reduced cloud traffic by 56% while still preserving 100% of critical and warning comfort events.

Interpretation

Adaptive edge filtering reduced unnecessary cloud workload before ECS/Fargate auto-scaling was required. This provides clearer HD-level evidence than cloud auto-scaling alone because it applies a research-inspired cloud-edge scalability technique: important events are offloaded to the cloud immediately, while low-priority telemetry is reduced at the edge.
